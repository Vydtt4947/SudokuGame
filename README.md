# Sudoku Fruit Game

Một trò chơi Sudoku vui vẻ được xây dựng với Pygame!

## 🎮 Tính Năng
- 3 mức độ khó (Easy, Medium, Hard)
- Gợi ý thông minh
- Nhạc nền và hiệu ứng âm thanh
- Giao diện đẹp mắt với chủ đề trái cây

## ⚠️ Lưu Ý Quan Trọng
**Phải tải folder `assets/` đầy đủ để game chạy được!**
- Âm thanh: `music1.mp3`, `music2.mp3`, `bubble.mp3`, `left.mp3`, `win.mp3`, `lose.mp3`
- Hình ảnh: `1.png` đến `9.png`, `25.png`, `hint.png`

## 📥 Cài Đặt

1. Clone project:
```bash
git clone https://github.com/Vydtt4947/SudokuGame.git
cd SudokuGame
```

2. Cài dependencies:
```bash
pip install pygame
```

3. Chạy game:
```bash
python sudoku_demo.py
```

## 📝 Ghi Chú
- Mọi người cập nhật code đầy đủ (không chỉ đoạn mã riêng lẻ)
- Luôn include folder `assets/` khi cập nhật
